# 15 — Exercise deterministic torrent installation

**What to build:** Let a user discover and install a fixture game through a local torrent or magnet source, using the same visible workflow and evidence as direct download without depending on a public swarm.

**Blocked by:** 07 — Deliver the Golden Journey

**Status:** ready-for-agent

- [ ] A loopback-only deterministic torrent fixture is available on Windows and Linux.
- [ ] Discovery, source selection, progress, setup, and Library verification occur through visible UI.
- [ ] No public tracker, peer, or credentialed provider is contacted.
- [ ] Installed bytes match the fixture payload and exactly one Library entry exists.
- [ ] Timeout, process cleanup, screenshots, logs, and event evidence follow the shared harness rules.
